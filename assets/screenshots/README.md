# Capturas de pantalla

Para mantener el `README.md` principal vivo, guarda aquí las capturas con estos nombres exactos:

| Fichero | Origen |
|---|---|
| `00_resumen.png` | Módulo 0 — Resumen general (con datos del año completo) |
| `01_fallos.png` | Módulo 1 — vista completa con el plano y el heatmap del pasillo |
| `02_srm.png` | Módulo 2 — tabla y ranking de SRM |
| `03_stv.png` | Módulo 3 — tabla y ranking de STV del anillo |
| `04_comparativa.png` | Módulo 4 — comparativa S1 vs S2 |

**Cómo capturar:**

1. Arranca la app: `streamlit run app.py`
2. Navega a cada módulo, ajusta el zoom del navegador para que entre la fila clave
3. Captura ventana (Win+Shift+S en Windows) o usa la extensión "Capture Full Page Screenshot"
4. Guarda como PNG (no JPG) en este directorio con el nombre indicado

Si cambias los nombres, actualiza las referencias en el `README.md` raíz.
